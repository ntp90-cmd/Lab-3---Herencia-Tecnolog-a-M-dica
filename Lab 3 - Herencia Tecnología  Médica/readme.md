# Sistema de gestion hospitalaria
## Laboratorio 3:herencia.
## Obed Tot- 26971

Programa desarrollado en Java para administrar trabajadores medicos,
gestionar citas, realizar reagendamientos y calcular la nomina del hospital.

## Funcionalidades

- Registrar y consultar trabajadores.
- Agregar jornadas de disponibilidad.
- Programar citas con asignacion manual o automatica de personal.
- Detectar conflictos de horarios.
- Consultar citas por estado o trabajador.
- Cambiar el estado de las citas.
- Reagendar citas y conservar el historial de cambios.
- Registrar ausencias y buscar alternativas para las citas afectadas.
- Calcular salarios y nomina por departamento.
- Consultar el porcentaje de ocupacion de la agenda.
- Mostrar notificaciones mediante la consola.

## Tipos de trabajadores

El sistema utiliza la clase abstracta TrabajadorMedico y cinco subclases

- DoctorGeneral.
- Cirujano.
- Enfermero.
- Radiologo.
- Terapeuta.
